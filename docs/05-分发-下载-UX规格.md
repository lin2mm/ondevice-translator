# 05 · 模型分发（永久免费的托管账）、下载管理器、UX 规格

## 1. 免费托管：462MB × N 用户怎么不花钱

App 包内只放 `manifest.json`（约 2KB）。权重要有地方下载，而"永久免费"意味着**不能有按流量计费的出口**。

| 方案 | 出站流量费 | 单文件上限 | 结论 |
|---|---|---|---|
| **Cloudflare R2** | **免费**（R2 的卖点就是不收 egress） | 5GB | 主推。免费层 10GB 存储够放 462MB + Q4 档 + 版本历史 |
| GitHub Releases | 免费但有软限 | 2GB/文件 | 兜底镜像；被限速时切回 R2 |
| Hugging Face 公共 repo | 公共仓库配额宽松，gated repo **不能**被 App 直连 | 无硬限 | 只能作为"我们自己搬运后的公共镜像"；TranslateGemma 系是 gated，必须搬运 |
| Vercel / Netlify / S3 / 对象存储按量 | 都要钱 | — | 不做默认 |

成本估算（说清量级，别骗自己）：1000 台设备各下一次 462MB ≈ **462GB**；R2 免费层能扛（存储 10GB 内、出站不计费），但请**开启 public access + 缓存**（Cloudflare CDN 命中后回源极少）。超过 1 万设备就要认真算账 → 应对：只发一个包（1.25-bit）、用 zstd/xz 预压缩（GGUF 已量化，再压约省 15–20%，代价是端上解压内存 → 用 `split` 成 2 个 part 流式解压）。

## 2. manifest 契约（App / CDN / CI 三方唯一接口）

由 `tools/build_manifest.py` 生成（**sha256 与体积全部实测，不手填**），字段语义见 `core/model_manifest.py`：

```json
{
  "schema": 1,
  "version": "2026.09.05-a",
  "updated_at": "2026-09-05T09:00:00Z",
  "glossary_schema": 1,
  "min_app_build": 12,
  "forced_update": false,
  "assets": [
    {
      "id": "Hy-MT2-1.8B-1.25Bit",
      "url": "https://cdn.example.com/models/Hy-MT2-1.8B-1.25Bit.gguf",
      "sha256": "<64 hex>",
      "size_bytes": 462000000,
      "quant": "1.25bit", "params_b": 1.8,
      "min_ram_bytes": 3000000000, "min_free_bytes": 500000000,
      "min_android_api": 28,
      "supports": ["text", "terminology", "style", "structured"],
      "languages": ["zh", "en"],
      "engine": "llama-cpp", "license": "Apache-2.0", "tier": 1
    }
  ]
}
```

规则（CI 强制，`Manifest.validate()` 已实现）：
1. `sha256` 必须 64 位小写十六进制；`size_bytes > 1MB`；`https`；`min_free_bytes ≥ size × 1.05`（否则提示会满盘）。
2. `languages` 必须含 `zh`+`en`；否则该产品不支持。
3. 未知字段 → 直接报错（拼错字段名静默失效是这类系统最容易的线上事故）。
4. 改模板/术语表格式 → 递增 `glossary_schema` / `min_app_build`，老 App 强制更新而不是加载出错。

## 3. 下载管理器（两端同一状态机）

```
idle → checking → planned(size, 目标盘)
     → downloading (断点续传 Range, 进度节流 200ms/1%, 可暂停)
     → verifying (流式 sha256, 30–60s on 462MB → 必须后台线程)
     → ready | corrupt(删+重试≤2) | no_space(引导清理) | offline(排队)
```

实现要求：
- **先写 `part` 文件 + `.part.json` 记 offset**；校验通过再原子 rename。中途被杀要能续传（4G 网下 462MB 一定会被打断）。
- 校验失败不要立刻重下整包：保留 90% 概率是 CDN 截断 → 用 Range 重取尾部 + 再校验。
- Wi-Fi 判断：iOS `NWPathMonitor`（`.expensive` 视为计费）、Android `ConnectivityManager.NetworkCallback`；用户开关"允许蜂窝下载"默认**关**。
- 失败退避 30s→2min→8min，最多 5 次；期间 UI 显示"已暂停（等待 Wi-Fi）"而不是转圈。
- 磁盘预算：先 `statfs` 查可用；不足时按 `downgrade_chain()` 换更小档（1.25bit → B 档），而不是让用户清空间。
- 安装后把 `manifest.version` 写进本地记录；升级只在 `forced_update` 或校验和不匹配时提示（不要静默重下 462MB）。
- 删除：设置里"释放 462MB"→ 删文件 + 保留 TM/术语（学习数据比模型重要得多）。

## 4. UI 规格（6 屏，中英双语，可全部本地化在 strings 里）

**① 主屏（文本翻译）**
- 顶部语言条：`自动 | 中 → 英 | 英 → 中`（点中间箭头交换并带上历史）
- 输入卡：多行、字数计数 + `≈N tokens`（用 `estimate_tokens`，让用户理解延迟）；粘贴自动检测语言并**立刻**开始翻译（300ms 防抖），无需按钮
- 输出卡：逐 chunk 流式；右上角计时 `本地翻译 · 0.6s`；长按 = 复制 / 朗读（系统 TTS）/ 收藏 / **编辑**（编辑=自学习入口）
- 底部工具条：`风格▾(正式/口语/技术/邮件)`、`术语▾`、`保形(保留换行/Markdown)`、`批量文档`
- 模型未就绪时：输入卡上方常驻 `需要下载 462MB（Wi-Fi）` + 进度；此时自动用 C 档（系统翻译）并显示 `当前：系统离线翻译（精度较低）`

**② 会话互译（类微软"对话"）**：中缝分割双向气泡，按住说话（ASR 用系统 `SpeechAnalyzer`/`SpeechRecognizer`，可选 sherpa-onnx）；每气泡长按可纠正 → 进 TM。

**③ 模型页**：当前档位、体积、校验和后 8 位、切换档位（显示"预计首字延迟 ×0.6 / 体积 +671MB"）、释放空间、检查更新。

**④ 术语表页**：CSV/TSV 导入导出、四色标记（enforce/hint/keep/forbid）、`self_check()` 错误就地红字（含"被长词遮蔽"警告）、按域分组（"公司术语/游戏/法律"）。

**⑤ 已学到页（自学习可视化，信任感来源）**：`翻译记忆 1,284 句（其中 96 句你改过）`、`候选术语 7 条 → 确认/忽略`、每条显示证据句数与来源；`清空学习数据`、`导出学习数据（用于自己训练）`。

**⑥ 历史/收藏**：7 天滚动，本地存储，可关。

**通用**：深色模式、字体随系统 Dynamic Type、离线状态条常驻、错误文案说人话（"这个包校验没通过，已重新下载尾部数据"而不是"error -1011"）。

## 5. 延迟预算（必须先定死再写代码，否则一定超时）

以 iPhone 15（A16）+ 462MB 1.25-bit 为例，**这些数需要你真机实测校准**（沙箱跑不了）：

| 阶段 | 目标 | 手段 |
|---|---|---|
| 冷加载（mmap） | ≤ 400ms | `use_mmap=true`，不解析全量；后台预加载一次 |
| 分句+保护+注入 | ≤ 3ms/1k 字 | 纯 CPU O(n)，已实现 |
| 首 token（prefill 150 tok） | ≤ 500ms | ctx 2048、threads 4、Metal |
| 生成 | ≥ 12 tok/s（可接受）/ ≥25（良好） | 超预算就切 B 档或减小 chunk |
| 整段 500 字 | ≤ 6s | 4 chunk 串行，UI 流式 |
| 内存峰值 | ≤ 1.1GB | KV 限制 + 告警卸载 |

## 6. 评测门禁（发布模型前，CI 里跑，别靠手测）

```
tools/eval_zh_en.py --dirs testsets/{blog,chat,legal} --engines hy-mt2-125,hy-mt2-q4,marian
```
- 指标：**chrF++**（sacrebleu）、COMET-Kiwi（无参考，需 GPU，跑在 CI 机器上）、术语命中率、数字/占位符错误率（必须 0）、超长句截断率。
- 门禁：新包相对上一个包在同一测试集上 **chrF++ 不得下降 >0.3**，`num_mismatch` 必须为 0，否则 manifest 不发布。
- 手机端另跑 `tools/bench_mobile.py`（tokens/s、峰值 RSS、机身温度、连续 20 句降速曲线）。
