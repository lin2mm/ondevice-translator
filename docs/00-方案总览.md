# 本地 AI 翻译 App（中英互译）· 方案总览

约束（你给的）：**iPhone 15 + Android 两个安装包 / 全免费且永久免费 / 要自学习 / 完全离线 / 最轻量化 / 只做中英互译**。

---

## 1. 一句话结论

> **自带一个 462MB 的翻译专用小模型（腾讯 Hy-MT2-1.8B 的 1.25-bit 量化，Apache-2.0），用 llama.cpp 跑；权重不进 App 包、由 App 自己从免费 CDN 下载；"自学习"不做训练，而是把用户改过的句子做成翻译记忆 + 从修改里统计挖术语，回灌进 prompt。iOS 侧用系统 `Translation` 框架做零体积兜底，因为 iPhone 15 本体永远用不了 Apple Intelligence。**

## 2. 为什么是这个组合（每个约束都对应一条硬事实）

| 你的约束 | 决定了什么 | 依据（本次实测/核实） |
|---|---|---|
| iPhone 15（A16 + 6GB） | **不能**把系统级大模型当主引擎。Apple Intelligence 要求 A17 Pro+ 且 8GB 内存，iPhone 15 / 15 Plus 被永久排除 → `FoundationModels.SystemLanguageModel` 在这台机器上 `isSupported = false`，没有软件更新能救 | Apple 支持口径 + 多家 2026 核对 |
| 完全离线 | 模型必须在设备本地；系统 `Translation` 框架的语言包虽离线但是"系统托管、不可控质量、无法注入术语表" → 只能当兜底，不能当主力 | iOS 18+ `Translation` 框架；iOS 26 起可在 SwiftUI 修饰符外直接 `TranslationSession(installedSource:target:)` |
| 中英互译 + 最轻量 | 不需要 33 语/200 语大模型。翻译**专用**小模型 > 通用多语模型同尺寸 | Hy-MT2-1.8B 官方口径：1.8B 整体超过微软等商用 API；TranslateGemma 4B（Q4 2.49GB）是同量级竞品但大一倍 |
| 全免费 / 永久免费 | ① 权重许可证必须宽松 → **Hy-MT2 系是 Apache-2.0**（Gemma 系是 Gemma Terms，条款更绕，且 HF 上 gated，用户手机不能直连下载）② 无云推理 = 0 边际成本，只剩下载流量 → 用**不收出站流量费**的对象存储（Cloudflare R2 免费层 10GB 存储 / 出站免费）或 GitHub Releases（单文件上限，公共仓库免费） | HF API 实测：`tencent/Hy-MT2-1.8B-1.25Bit-GGUF` → `license: apache-2.0`，`Hy-MT2-1.8B-1.25Bit.gguf = 462MB`；`google/translategemma-4b-it` 返回 "Access to model ... is restricted" |
| 要自学习 | 手机端不能梯度更新（量化权重不可训、1.8B 全参微调要几十 GB 显存）。可行的是 **推理期自适应**（翻译记忆 few-shot + 术语挖掘），以及可选的"在电脑上练一个 LoRA 再装回手机" | 见 `core/learn.py`（已实现并通过单测） |

> ⚠️ "全免费"有一个绕不开的钱：**iOS 上架要 Apple 开发者账号 99 USD/年**。不想付就只有两种玩法：① TestFlight（90 天过期、1 万人上限，不能永久）；② 自签 / AltStore / SideStore（免费账号 7 天重签、最多 3 个 App）。Android 侧 Google Play 是一次性 25 USD；国内分发可完全免费（各家商店 + 直接 APK 侧载）。

## 3. 模型阶梯（免费、可下载、按机型选）

| 档 | 权重 | 实测体积 | 跑在哪 | 定位 |
|---|---|---|---|---|
| **A 主力** | `tencent/Hy-MT2-1.8B-1.25Bit-GGUF` | **462 MB** | iPhone 15 / Android 6GB+ 都能跑 | 默认。中英质量最高/体积比 |
| A′ 质量档 | `tencent/Hy-MT2-1.8B-GGUF` Q4_K_M | **1133 MB** | 8GB+ 机型，用户在设置里手动开 | 长文、术语密集文档 |
| B 极限档 | Opus-MT / Marian `en↔zh` ONNX（ONNX Runtime Mobile） | 约 100–300 MB（**需自行实测**） | 4GB 老机 | 只做"能看懂"，不做"译得好" |
| C 零体积兜底 | iOS `Translation` 框架系统包 / Android ML Kit `translate`（每语言约 30MB，59 语） | 0（系统管） | 全部 | 模型没下完 / 内存被系统收回时用；不能注入术语表 |
| 参考对比 | TranslateGemma-4B Q4_K_M 2.49 GB / litert int8 3.90 GB；Gemma 4 E2B litert-lm 2.01 GB | — | 8–12GB 旗舰 | 体积不符合"最轻量"，本方案不选 |

**内存预算**（A 档）：462MB 权重（mmap，可被系统随时回收重映射）+ KV cache（`ctx 1536`、1.8B 24 层量级 → 约 200–400MB）+ 运行时 ≈ **峰值 0.8–1.1GB**。iPhone 15 的 6GB 够用，但要：只用 CPU+Metal、限制 ctx、监听内存告警立刻 `unload`。

## 4. 三层架构（代码已在仓库里）

```
UI (SwiftUI / Compose)
  └─ Translator 编排层  ← 行为规格 = core/*.py（39 条单测）
       ├─ 1 语言检测（zh/en 二分类，脚本占比，不引 fasttext）
       ├─ 2 分句 + chunk 打包（token 预算 150）        core/segmenter.py
       ├─ 3 占位符保护 ⟨num1⟩ ⟨fmt2⟩（数字/URL/代码不送模型）
       ├─ 4 上下文注入：术语表 + 自学习例句            core/glossary.py, core/learn.py
       ├─ 5 prompt 模板（Hy-MT2 官方 6 类模板）        core/prompt.py
       ├─ 6 Engine.generate（llama.cpp / Apple / ML Kit）
       ├─ 7 输出体检 + 失败重试（温度降级）             core/validate.py
       └─ 8 还原哨兵 → 术语强制 → LRU 缓存（改术语即失效）
  └─ ModelStore：manifest + sha256 + 断点续传 + 磁盘预算  core/model_manifest.py
```

## 6. 我在这个沙箱里验过什么 / 没验什么

**验过**：核心逻辑 39 条单测全绿（分句、占位符保护与还原、体检重试、术语表、自学习挖掘、manifest 校验与降级选包、缓存失效）；HF 上各仓库的真实体积与许可证；官方 prompt 模板与采样参数（模型卡原文）。

**没验（你必须在真机补）**：手机上的 token/s 与发热、内存峰值、以及"1.25-bit 量化后中英质量掉多少"。沙箱只有 2 核 1GB 内存、没有 Xcode/Gradle/CMake，**跑不了模型、也编不出 ipa/apk**。`docs/06` 末尾给了补测清单和验收阈值。
