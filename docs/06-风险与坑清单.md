# 06 · 风险与坑清单（按"会让项目死掉"的程度排序）

## A. 会在真机上直接炸的

1. **Metal 未生效导致慢 3–5 倍且不报错**（iOS）：`LLAMA_METAL_EMBED_LIBRARY=ON` 没开 → 静默 CPU。判据：日志里必须出现 `METAL` 后端；跑分对比 M 系列机应有明显差距。
2. **Android 16KB 页**：预编译 `.so` 未加 `-Wl,-z,max-page-size=16384` → 16KB 设备 `UnsatisfiedLinkError`。必须在 16KB 模拟器上跑一次冒烟。
3. **权重放错目录**：iOS 放 `tmp/`（被清理）、Android 放 `cacheDir`（被清理）或 `filesDir` 但没写 backup 排除（462MB 进 iCloud/Auto Backup，用户空间炸了就来差评）。
4. **iOS jetsam**：6GB 机器上 mmap 权重 + KV cache + SwiftUI 常驻，容易在切后台/多任务时被杀。必须实现内存告警 → `unload()`，并接受"下次冷加载 300ms"。
5. **ctx 不设上限**：用户粘一篇 2 万字，KV cache 直接把内存吃光。`core/segmenter.pack()` 的 150-token chunk + `max_new_tokens` 是硬闸；两端都要照抄。
6. **停止词没设全**：译文里出现自问自答（模型继续生成下一轮 user/assistant）。已在 `OutputGuard` 黑名单加 `"user"`、`"###"`、`"Translate the following"`。

## B. 会毁掉口碑的（质量类）

7. **小模型幻觉**：1.8B 在长句/低置信时会"补内容"。缓解：体检层（`core/validate.py` 的 `len_ratio`/`num_mismatch`）+ UI 明示"本地模型，重要文本请复核"。这条文案必须留着，是法律与口碑的双重保险。
8. **数字/单位/电话/金额出错是最致命的**：所以 `num` 类占位符被保护、且校验"数字集合必须包含源文数字集合"。注意"美元/元"这类中文单位**故意不保护**（要模型译成 `$`/`USD`），别改错。
9. **术语表改了但译文没变** = 缓存没失效。已修（`_glossary_v`/`_learn_v` 进缓存 key），两端必须一致，否则用户觉得"这功能假的"。
10. **`language` 用 ISO 代码而非全名**：Hy-MT2 官方要求"中文指令配中文语言名（英语）、英文指令配 English"。写 `en` 会掉质量，这类细节在 1.8B 上不是玄学，是实测差距。
11. **温度照抄 0 或 1.0**：官方推荐 0.7/0.6/20/1.05；温度 0 会让小模型重复退化，1.0 会跑飞。重试才降到 0.3。
12. **自学习把用户教坏**：一次误改就固化术语 = 灾难。所以 `mine_candidates` 要求 ≥2 句独立证据 + 背景频率过滤，且必须用户确认才 `enforce`；面板可逐条删。

## C. 会上架/合规被打回的

13. **Android 划词用 AccessibilityService**：Play 政策禁止把辅助功能用于内容抓取（微软/Google 自家翻译走的是系统选区，你有豁免，你没有）。→ 用 `ACTION_PROCESS_TEXT` 选区上下文 + 分享 + 截图 OCR；国内版按 build variant 单独开。
14. **Apple 审核"为什么不需要网络"** 与 **"是否声称 AI 能力"**：需说明端侧模型、开源许可、内容安全（用户自己文本无过滤 → 声明不生成内容仅翻译，且在 App 描述里别写"ChatGPT 级别"）。
15. **Gemma 系许可证**（若做 A′ 档）：Gemma Terms 有条款，且 HF repo **gated** —— App 里绝不能直连 gated 链接（用户下不到，且你把条款规避了）。搬运 + 附条款。
16. **"永久免费"的成本模型**：唯一确定的支出是 Apple 开发者 99 USD/年（不付就没有永久安装的 iOS 版；TestFlight 90 天、自签 7 天）。CDN 用 R2 免出站费可长期扛；一旦设备量 >1 万，要么加赞助入口要么砍档位。**不要在没算清流量前承诺"永久"。**
17. **隐私声明与实现不一致**：埋点绝不能带原文片段（很多团队在 debug log 里带了，隐私标签就成假话）。本产品可完全不上传，那就把"无网络请求"做进验收：飞行模式下全流程可用 + 抓包 0 请求。
18. **中国区**：Apple Intelligence/FM 能力受地区与语言限制（`SystemLanguageModel` 需用户开启 AI 且设备支持），`Translation` 框架语言包也可能需要系统下载。别写"iOS 内置翻译一定可用"，写"若系统语言包缺失会自动回落到本地模型"。
